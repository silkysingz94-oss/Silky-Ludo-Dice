📖 About This Game

Singz vs The Next Player is a two-player JavaScript dice challenge developed using HTML, CSS and JavaScript. Players take turns rolling a virtual six-sided dice. Each roll adds points to the active player's score. The first player to reach 30 points wins the game. The application demonstrates JavaScript variables, functions, DOM manipulation, event listeners, conditional statements, random number generation and CSS animations.
